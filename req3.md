Требования для реализации новой функциональности 
1. Общая задача

Позволяnm сохранять данные отчета на локальную машину в виде JSON-файла.

Сохраняет отчеты в структуре папок по месяцам.

Позволяет просматривать все сохраненные отчеты и редактировать их через браузер.

Подставляет данные из JSON обратно в форму для редактирования.

Сохраняет новые изменения в JSON, не удаляя предыдущие версии, с возможностью сохранения новой версии с датой изменения.

2. Сохранение отчета

В режиме предпросмотра при нажатии кнопки «Сохранить» формируется JSON-файл с данными формы.

JSON-файл сохраняется локально в папку:

/Отчеты/
    /ГГГГ-ММ/
        report_YYYY-MM-DD_HH-MM-SS.json


где:

ГГГГ-ММ — текущий год и месяц.

YYYY-MM-DD_HH-MM-SS — точная дата и время формирования отчета.

Если отчет за текущий день уже существует, новые изменения сохраняются с новым timestamp, не удаляя старые версии.

После нажатия кнопки созранить очищается localstorage cсданными черновикаи удаляет их из localstorage.

3. Просмотр отчетов

В отдельной вкладке yfнстранице проверки ченовиков вместо кнопки начать заполнение сделать кнопку Ретроспектива в которой браузер отображает список всех сохраненных отчетов в удобном виде

Данные списка формируются из структуры папок и файлов на локальной машине.

Пользователь видит:

Дату и время отчета

Название файла

При клике на конкретный отчет JSON загружается и данные подставляются в форму для редактирования.

4. Подстановка данных в форму

Загруженные из JSON данные автоматически заполняют соответствующие поля формы.

Пользователь может редактировать данные.

При повторном сохранении создается новая версия JSON, сохраняемая по той же структуре папок.

5. Структура JSON

JSON должен содержать:

{
  "metadata": {
    "date_created": "YYYY-MM-DDTHH:MM:SS",
    "last_modified": "YYYY-MM-DDTHH:MM:SS",
    "report_id": "уникальный ID",
    "version": 1
  },
  "data": {
    "field1": "значение",
    "field2": "значение",
    "...": "..."
  }
}


report_id — уникальный идентификатор отчета (можно UUID).

Каждое редактирование увеличивает version на 1.

6. Ограничения

Реализация без сервера. Все файлы хранятся на локальной машине.
